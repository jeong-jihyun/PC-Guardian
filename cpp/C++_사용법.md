# PC-Guardian C++ 네이티브 버전

PowerShell 없이, 순수 C++ (Win32 API)로 작성하고 실제로 크로스 컴파일까지 거쳐 만든 **진짜 .exe 파일**입니다.

---

## 1. 실행 방법

1. `PC-Guardian.exe` 다운로드
2. **마우스 오른쪽 클릭 → "관리자 권한으로 실행"**
   (방화벽 차단, 복원 지점 생성/복구 기능에 관리자 권한이 필요합니다. 관리자 권한 없이 실행해도 창은 뜨지만 해당 기능에서 오류가 날 수 있습니다)
3. 끝입니다. 명령어 입력, 실행 정책 설정, 아무것도 필요 없습니다.

---

## 2. 포함된 기능 (전부 네이티브 Win32 API)

| 메뉴 | 사용 기술 |
|---|---|
| 대시보드 | 상태 요약 |
| 실시간 감시 | 프로세스/시작프로그램/블루투스 스냅샷 비교 (Toolhelp32, 레지스트리, Bluetooth API) |
| 침입 차단 | RDP 로그인 실패 자동 차단(Windows 이벤트 로그 4625 + netsh 방화벽), 수동 IP/대역 차단, 목록 파일 불러오기 |
| 파일 무결성 | SHA-256 해시 비교 (Windows CryptoAPI) |
| 복구/백업 | 시스템 복원 지점 생성(SRClient API) / 목록조회·복원(WMI) |
| 격리함 | 프로세스 종료 (Toolhelp32 + TerminateProcess) |
| 증거/신고 | 스크린샷(GDI), 로그인 실패기록/차단목록/활동로그 수집, 신고 리포트 자동 생성 |
| 로그 | 활동 로그 뷰어 |

---

## 3. 소스코드(`PCGuardian.cpp`)도 같이 드립니다

- 투명성을 위해 전체 소스를 포함했습니다. 코드를 직접 확인하실 수 있습니다.
- 직접 다시 빌드하고 싶으시면 (예: 수정 후): Windows에 Visual Studio가 있다면 그대로 컴파일 가능하고,
  제가 사용한 방식(Linux에서 mingw-w64로 크로스 컴파일)을 쓰실 수도 있습니다.

---

## 4. 저장 위치

`%USERPROFILE%\PC-Guardian\` 폴더 (이전 버전과 동일한 구조)
- `Logs\`, `Evidence\`, `State\` (차단 IP·격리 이력 등 설정은 텍스트 파일로 저장)

---

## 5. 참고

- 이 프로그램은 PowerShell 버전과 **기능은 거의 동일**하고, 실행 방식만 "진짜 실행파일"로 바뀐 것입니다.
- 창 크기는 고정입니다(크기 조절 비활성화) — 레이아웃이 깨지지 않도록 의도적으로 그렇게 만들었습니다.
