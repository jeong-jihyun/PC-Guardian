# PC-Guardian GUI 버전 사용법

---

## 1. 실행 방법

1. `PC-Guardian-GUI.ps1`을 원하는 폴더에 저장
2. 시작 메뉴에서 **"Windows PowerShell"** 검색 → **마우스 오른쪽 클릭 → "관리자 권한으로 실행"**
   (GUI 창이므로 관리자 권한 없이도 뜨긴 하지만, 방화벽 차단·복원 지점 기능은 관리자 권한이 꼭 필요합니다)
3. 아래 입력:

```powershell
cd C:\Users\본인계정\Downloads
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\PC-Guardian-GUI.ps1
```

창이 뜨면 왼쪽 메뉴로 각 기능을 오갈 수 있습니다.

## 2. 적용이 안 된 기능과 그 이유

요청하신 기능 중 아래 4개는 **넣지 않았습니다.** 이유를 짚고 넘어갈게요.

| 기능 | 왜 개인 PC엔 적용 안 되는지 |
|---|---|
| WAF (웹 방화벽) | 웹사이트/웹서버로 들어오는 HTTP 요청을 걸러내는 기술입니다. 내 PC가 웹사이트를 운영 중이 아니면 걸러낼 "요청" 자체가 없습니다. |
| Rate limiting | "짧은 시간에 너무 많은 요청"을 제한하는 건, 내 PC가 요청을 **받는 쪽(서버)**일 때 의미가 있습니다. 개인 PC는 보통 요청을 보내는 쪽입니다. |
| GeoIP 실시간 국가차단 | 실시간으로 "이 IP가 어느 나라냐"를 판정하려면 외부 조회 서비스(API)가 필요합니다. 대신 **차단하고 싶은 IP/대역 목록을 직접 불러와 적용**하는 기능(②번)으로 대체했습니다. 원하는 국가의 IP 대역 목록을 텍스트 파일로 구해오시면 그대로 불러와 차단할 수 있습니다. |
| DDoS 완화 (Cloudflare 등) | DDoS는 "서버"를 마비시키는 공격입니다. 개인 PC는 애초에 DDoS의 공격 대상이 되는 경우가 거의 없습니다. (혹시 집 인터넷 자체가 먹통이 되는 상황이라면, 이건 ISP/공유기 쪽 문제라 소프트웨어로 해결되지 않고 통신사에 문의하셔야 합니다) |

나머지 요청하신 기능은 **전부 들어가 있습니다.**

## 3. 메뉴별 설명

### 📊 대시보드
한눈에 보는 요약 화면. 마지막 스냅샷 시각, 감시 켜짐/꺼짐, 차단된 IP 수, 격리된 항목 수를 보여줍니다.

### 👁 실시간 감시
설정한 시간마다 자동으로 PC 상태(프로그램/시작프로그램/블루투스/예약작업)를 확인하고, 새로 생긴 게 있으면 목록에 표시합니다.

### 🚫 침입 차단
- **① 자동 차단**: 원격 로그인(RDP)이 설정한 횟수 이상 실패하면, 그 IP를 윈도우 방화벽에서 자동으로 막습니다. (fail2ban과 똑같은 원리)
- **② 수동 차단**: 직접 IP나 대역(예: `203.0.113.0/24`)을 입력해서 차단하거나, 미리 만들어둔 차단 목록 파일을 통째로 불러와 적용할 수 있습니다.

> ⚠️ 참고: 원격 데스크톱(RDP)을 켜두지 않은 PC라면 ①번 기능은 감지할 로그인 시도 자체가 없어 의미가 적습니다. 그래도 켜두면 혹시 모를 상황에 대비가 됩니다.

### 🗂 파일 무결성
지정한 폴더(예: 중요 문서 폴더)의 모든 파일의 "지문(해시값)"을 기록해두고, 나중에 다시 검사해서 **변경/삭제/추가된 파일**을 찾아줍니다. 랜섬웨어나 파일 변조를 가장 확실하게 잡아내는 방법입니다.

### ♻ 복구/백업
윈도우 시스템 복원 지점을 만들고, 목록에서 골라 되돌릴 수 있습니다.

### 🔒 격리함
실행 중인 프로그램을 보고 의심되면 종료(격리)할 수 있습니다. 모든 격리 이력이 기록으로 남습니다.

### 📁 증거/신고
- **스크린샷 캡처**: 이상 화면을 바로 저장
- **증거 폴더 생성**: 로그인 실패 기록, 차단 목록, 활동 로그, 스크린샷을 한 번에 모아 폴더로 저장
- **신고 리포트 생성**: 위 내용을 정리된 텍스트 파일로 만들어줍니다 → 이걸 들고 KISA(118)나 경찰 사이버수사국에 신고하시면 됩니다

### 📜 로그
모든 활동 기록을 시간순으로 볼 수 있습니다.

## 4. 처음 사용 시 추천 순서

1. **복구/백업** → "복원 지점 생성" (지금을 안전지점으로 저장)
2. **파일 무결성** → 중요 폴더 추가 → "기준 해시 생성"
3. **침입 차단** → "자동 차단 감시 시작" (RDP 켜져 있다면)
4. **실시간 감시** → 감시 시작 (켜두고 평소처럼 사용)
5. 이상이 느껴지면 → **파일 무결성 "지금 검사"**, **격리함**에서 의심 프로그램 종료
6. 피해가 확실하면 → **증거/신고**에서 증거 폴더 생성 → 신고 리포트 생성 → KISA/경찰에 신고

---

## 5. 저장 위치

`%USERPROFILE%\PC-Guardian\` 폴더 안에 전부 저장됩니다.
- `Logs\` : 활동 로그
- `Snapshots\` : PC 상태 스냅샷
- `Evidence\` : 스크린샷, 증거 폴더, 신고 리포트
- `state.json` : 차단 IP·감시 폴더·격리 이력 등 설정 (프로그램 껐다 켜도 유지됨)
