# PC-Guardian 사용법

개인 윈도우 PC를 "평소에 지켜보고, 문제 생기면 되돌리는" 보호 프로그램입니다.
**공격자를 공격하거나 추적하지 않습니다.** 오직 내 PC 안에서만 동작합니다.

---

## 1. 실행 방법

1. `PC-Guardian.ps1` 파일을 다운로드한 폴더로 이동
2. 시작 메뉴에서 **"Windows PowerShell"**을 검색
3. **마우스 오른쪽 클릭 → "관리자 권한으로 실행"**
4. 열린 창에 아래 명령어 입력 (파일 경로는 본인 상황에 맞게 수정)

```powershell
cd C:\Users\본인계정\Downloads
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\PC-Guardian.ps1
```

- `Set-ExecutionPolicy` 줄은 "이 창에서만" 스크립트 실행을 허용하는 명령입니다.
  창을 닫으면 원래대로 돌아가니 보안상 걱정 안 하셔도 됩니다.

---

## 2. 처음 쓸 때 추천 순서

| 순서 | 메뉴 | 왜 하는지 |
|---|---|---|
| 1 | **4번: 보호 지점 만들기** | 지금 상태를 "안전한 지점"으로 저장. 문제 생기면 여기로 되돌릴 수 있음 |
| 2 | **1번: 스냅샷 찍기** | 지금 실행중인 프로그램/블루투스 기기 등을 기록 |
| 3 | **3번: 실시간 감시 시작** | 평소에 켜두면 자동으로 주기적 확인 + 이상 생기면 기록 |

그 다음부터는:
- **이상하다고 느껴질 때** → 2번(비교)으로 "뭐가 새로 생겼는지" 확인
- **의심되는 프로그램 발견** → 6번(격리)으로 종료
- **상태가 심각하게 꼬였을 때** → 5번(복구)으로 이전 지점으로 되돌리기

---

## 3. 각 메뉴가 하는 일 (쉬운 설명)

- **1. 스냅샷 찍기**: 지금 이 순간 PC 상태(프로그램 목록, 시작프로그램, 블루투스 기기, 네트워크 연결, 예약작업)를 사진 찍듯 저장합니다.
- **2. 비교하기**: 저장해둔 두 스냅샷을 비교해서 "새로 생긴 것"만 찾아 보여줍니다.
- **3. 실시간 감시**: 정해진 시간마다 자동으로 1번+2번을 반복합니다. 창을 열어두면 계속 지켜봅니다.
- **4. 보호 지점 만들기**: 윈도우 자체 기능인 "시스템 복원 지점"을 만듭니다. 나중에 문제 생기면 이 시점으로 PC를 되돌릴 수 있습니다.
- **5. 복구하기**: 만들어둔 복원 지점 목록을 보여주고, 선택하면 그 시점으로 되돌립니다. (PC가 재부팅됩니다)
- **6. 의심 프로그램 종료**: 실행중인 프로그램 중 하나를 골라서 강제 종료합니다. (삭제는 아니고, 지금 실행만 멈춤)
- **7. 블루투스 기기 보기**: 현재 PC가 인식하고 있는 블루투스 기기 목록을 보여줍니다. 모르는 기기는 윈도우 설정에서 직접 제거하도록 안내합니다.
- **8. 로그 폴더 열기**: 지금까지 기록된 모든 로그를 폴더로 엽니다.

---

## 4. 파일 저장 위치

모두 `내문서\PC-Guardian\` 폴더 안에 저장됩니다. (정확히는 `%USERPROFILE%\PC-Guardian`)

- `Snapshots\` : 찍어둔 PC 상태 기록들 (JSON 파일)
- `Logs\` : 날짜별 활동 로그 (언제 뭘 했는지, 뭐가 감지됐는지)

나중에 신고가 필요해지면 이 `Logs` 폴더 내용이 증거 자료로 쓰일 수 있습니다.

---

## 5. 주의사항

- 이 프로그램은 **감시·백업·복구·격리(종료)만** 합니다. 다른 컴퓨터에 어떤 요청도 보내지 않습니다.
- "새로 생긴 것 = 무조건 악성"은 아닙니다. 본인이 방금 설치한 프로그램이거나 새로 산 블루투스 이어폰일 수도 있어요. 먼저 확인부터 하세요.
- 정말 심각한 감염(랜섬웨어 등)이 의심되면, 이 스크립트보다 **정식 백신 프로그램의 전체 검사**를 먼저 돌리는 게 우선입니다. 이 프로그램은 백신을 대체하지 않고, 백신과 같이 쓰는 "감시+복구" 보조 도구입니다.
